# Fonts

The film renders with these fonts:

| env var | default | used for |
|---|---|---|
| PV_F_MONO   | C:/Windows/Fonts/consola.ttf   | monospace body |
| PV_F_MONO_B | C:/Windows/Fonts/consolab.ttf  | monospace bold |
| PV_F_CJK    | C:/Windows/Fonts/msyh.ttc     | CJK glyphs |
| PV_F_SYM    | C:/Windows/Fonts/seguisym.ttf | math symbols (∃ ⟨ ⟩ ⊢ ∀) |

Set any var to a substitute path if the default is missing.
